# ReSellHub

ReSellHub is a web-based marketplace for buying and selling second-hand and recycled goods. The platform promotes sustainable living by helping users give unwanted items a second life while reducing waste.

## Features
- User registration and login (Firebase Authentication)
- Product listing with image upload
- Search products by keyword
- Category filtering
- Wishlist (Saved Products)
- User profile management
- Dashboard with data visualization
- AI Image Search (Gemini Vision)
- Responsive design

## Technologies Used
- React
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- JavaScript
- HTML/CSS
- Chart.js
- Vercel
